# BLOOMKEEPER

> *"The only weapon is light. The only victory is peace."*

A stylized 3D low-poly pacifist action/puzzle game built in Godot 4 for the **Godot India Community Mini Jam 2026**.

---

## 🌟 Game Overview

You are a light-bearer inside a corrupted sanctuary. Dark shadow creatures aggressively chase you, but you have no conventional weapons. 

Your sole ability is the **Bloom Pulse**—an expanding wave of light that calms hostile creatures and transforms them into peaceful glowing shrines, restoring life and light to the sanctuary.

---

## 🎮 Controls

- **WASD / Arrow Keys**: Move
- **Shift**: Dash Evade
- **E / Right Mouse Button**: Bloom Pulse (Tap for 3m wave, Hold to Charge up to 7.5m wave)
- **ESC**: Pause Game / Resume
- **R**: Restart Sanctuary (on Victory or Game Over)

---

## 🍃 Core Gameplay Loop

1. **Evade** shadow creatures (Prowlers) using WASD movement and Shift Dash.
2. **Position** yourself strategically near corrupted creatures.
3. **Use Bloom Pulse** (E / RMB) to expand a light wave.
4. **Pacify** creatures into glowing peaceful shrines.
5. **Restore the Sanctuary**: Each pacified creature brightens the sanctuary lighting, clears dark fog, and brings warmth back to the world.
6. **Victory**: Pacify all 5 corrupted spirits to restore the sanctuary!

---

## 🛠 Tech Stack & Build

- **Engine**: Godot Engine 4.7.1
- **Renderer**: GL Compatibility (Optimized for Web/HTML5 browser play)
- **Platform**: Web (HTML5) & Desktop Windows
