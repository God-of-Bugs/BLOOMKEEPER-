# BLOOMKEEPER — ASSET LICENSES & ATTRIBUTION

## Project Asset Inventory

### 1. 3D Models & Meshes
- **Player Mesh**: Original procedural low-poly lantern-bearing adventurer composed from built-in `SphereMesh`, `CapsuleMesh`, and `CylinderMesh` primitives (Godot Engine).
- **Prowler Mesh**: Original procedural wood-and-root creature composed from built-in `SphereMesh` and `CapsuleMesh` primitives (Godot Engine).
- **Forest & Arena**: Original procedural `MultiMeshInstance3D` trees, ground cover, mushrooms, fireflies, built-in `BoxMesh` ground and boundaries, and `CylinderMesh` bloom clearings.
- **License**: These meshes are procedurally composed in this project from Godot Engine built-in primitives. Godot Engine is MIT licensed; see the Godot Engine license for the engine itself. No external model, texture, or font assets are used. The composition is original project content; do not interpret this as a third-party license grant.

### 2. Materials & Shaders
- **Sanctuary Materials**: Custom Godot `StandardMaterial3D` with albedo, emission, and roughness parameters.
- **License**: Project-authored material settings; no external shader or material asset is used. No separate third-party license applies to these project settings.

### 3. Audio & Sound Effects
- **Bloom Pulse Sound**: Synthesized 44.1kHz WAV chime tone (procedural AudioStreamWAV).
- **Creature Pacification Sound**: Synthesized C5 major resolution chord (procedural AudioStreamWAV).
- **Damage Sound**: Synthesized low warning thud (procedural AudioStreamWAV).
- **Victory Sound**: Synthesized sanctuary harp chord (procedural AudioStreamWAV).
- **License**: Sound samples are generated procedurally by project code at runtime; no external audio files or samples are included. The generated audio is not attributed to an external author or source.

### 4. Fonts & UI
- **UI Fonts**: Default Godot system font (`Theme`).
- **License**: The UI uses Godot's built-in default theme/font resources. No separate font files are bundled. Refer to the Godot Engine license for Godot-distributed resources.
